# Hat İzi · Calligraphy Trace

Motifi kalemi kaldırmadan tek çizgide çiz

Bir noktaya dokunarak başla, sonra çizgiyle bağlı komşu noktalara geç. Her çizgi yalnızca bir kez çizilebilir. Tüm çizgiler altın mürekkeple dolunca motif tamamlanır. Doğru başlangıç noktası çoğu zaman tek bağlantılı olanlardandır.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Özgün Oyunlar merkez uygulamasının oyunu; ortak motor: [ozgun-motoru](https://github.com/taktemurr-ops/ozgun-motoru).
